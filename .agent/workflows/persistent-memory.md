# 🔁 專案記憶持久化工作流 (Persistent Memory Workflow)

本工作流旨在解決 AI 跨對話「健忘」的問題，應在任何新專案啟動或重大變更後執行。

### 1. 初始化記憶檔案
- 建立 PROJECT_MEMORY.md：記錄專案目標、已達成共識、當前進度、以及曾遇到的報錯/坑洞。
- 建立 AI_RULES.md：記錄對 AI 的特定開發規範（如命名法、特定語音、UI 限制）。

### 2. 資料同步規範
- 每次對話結束前，AI 必須摘要本次對話的最佳決策，並更新至 PROJECT_MEMORY.md。
- 每次開啟新對話，使用者應先告知 AI 讀取這兩個檔案。

### 3. 持久化維護
- 定期清理過時的決定紀錄，保持檔案精簡。
- 確保技術架構的變更即時反應在文件中。
