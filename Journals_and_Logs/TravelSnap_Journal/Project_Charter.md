# 旅刻拍拍誌 (TravelSnap Journal) - 專案總綱

## 1. 專案願景 (Project Vision)
打造一款專為 **40+ 活躍族群** 設計的數位生活助手，協助使用者在旅行中輕鬆記錄感悟、整理美感照片，並透過一鍵生成的「創意貼圖」在社交圈展現生命力。

## 2. 目標客群 (Target Audience)
- **核心特徵：** 40歲以上，熱愛出遊、社交與持續學習。
- **痛點：** 市面 App 字體太小、功能層級過深、充斥過多 IT 術語、對社交分享（Threads/LINE）的操作不夠直覺。
- **需求：** 高質感視覺、大型點擊區、穩定安全感、極簡操作流。

## 3. UI/UX 設計準則 (Design Guidelines)
- **品牌調性：** 優雅、質感、暖心、有深度。
- **字體規範：** 全域大字體方案 (Headline 20px+)，確保戶外強光下易讀。
- **互動邏輯：** 扁平化層級、大面積按鈕、手勢防誤觸。
- **品牌圖示：** 暖橘與深青漸層，結合鏡頭與拍立得剪影。

## 4. 產品功能地圖 (Feature Roadmap)
- [ ] **時光相冊：** 本地優先的照片管理，自動分類，隱私保障。
- [ ] **感悟筆記：** 支援語音轉文字、快速情緒標籤、手繪標註。
- [ ] **創意貼圖：** 一鍵 AI 自動去背，生成符合 LINE 規格 (370x320) 的貼圖包。
- [ ] **社交中心：** 採用系統級分享機制，完美支援 LINE、Facebook、Threads 等平台。

## 5. 技術架構 (Technical Stack)
- **框架：** Flutter (支援 Android/iOS/Web)。
- **存儲：** 本地優先 (SQLite)，雲端備份為選配 (Google Drive/iCloud)。
- **開發環境：** VS Code (主要) / Android Studio (配備)。
