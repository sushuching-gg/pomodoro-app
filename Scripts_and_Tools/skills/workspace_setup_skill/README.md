# Workspace Setup Skill (工作區建立與專案初始化技能)

## 背景描述 (Background)
過去因為習慣直接打開 Antigravity 就開啟新的連線與對話，在沒有指定特定資料夾（工作區）的情況下，AI 會被迫在系統深處的預設路徑（如 C槽 .gemini）建立暫存資料夾來存放專案檔案。這會導致專案檔案難以尋找，且多個不同專案混雜在一起難以管理。

## 解決方案：新專案建立 3 步驟 SOP

為了確保未來的每一個新專案都能夠獨立、乾淨且易於管理，請嚴格遵守以下三個步驟：

### 步驟 1：打開檔案管理員 (Create Directory)
- 決定新專案的存放位置（例如你的 D 槽、Documents 或桌面）。
- 在該位置**建立一個全新的空資料夾**，並給予清晰的專案名稱。
- *範例：D:\Workspace\Company_Internal_System*

### 步驟 2：把位置先站好 (Initialize Context)
- 使用程式碼編輯器（例如 VS Code）或終端機，**開啟剛剛建立的那個資料夾**。
- 這個動作的意義是「佔好地盤」，讓 AI 知道這個資料夾就是目前的工作範圍。

### 步驟 3：喚醒 Antigravity (Call AI)
- 在已經開啟該資料夾的環境下，打開 Antigravity 並建立新的 Conversation。
- 這個時候下達任務，AI 所產生的所有檔案（含架構與記憶檔），都會**自動且精準地降落在這個新資料夾內**。

## 預期成果 (Expected Outcome)
透過這個專屬技能，未來所有的檔案去向都會完全由主導權掌控，確保每一個專案完全解耦（Decoupled），再也不會發生找不到檔案的窘境。
