# 📜 旅刻拍拍誌 - AI 協作開發準則 (AI_RULES.md)

1. **使用者體驗 (UX) 第一：** 按鈕點選區域必須大於 88x88 px (即便 UI 看起來沒那麼大，透明點選區也要擴張)。
2. **零術語：** 向用戶展示的文字禁止出現「SDK、路徑、座標、渲染、去背 (改用創作或美化)」等 IT 詞彙。
3. **繁體中文：** 語系預設且唯一使用繁體中文。
4. **異常處理：** 所有涉及照片存取、分享的動作，必須有溫暖的錯誤提示說明，而非跳出 Null 或 Error Code。
5. **程式碼更新：** 每次重大功能的實作完成後，AI 必須主動提更新 PROJECT_MEMORY.md 的進度部分。
