# 旅刻拍拍誌 - 專案核心技能與關鍵技術 (Skills & Expertise)

本專案結合了以下多項專業領域技能，以確保產品能精準服務 40+ 菁英族群：

## 1. 無障礙與高齡友善 UI/UX 設計 (Inclusive Design)
- **視覺生理優化：** 針對 40+ 族群可能存在的視覺需求，實施特大字體排版、高色彩對比度，以及避免使用細小線條的 Icon 設計。
- **認知心理設計：** 採用「低認知負載」的操作流程，功能名稱直覺化，減少術語，確保無需說明書即可上手。
- **物理操作輔助：** 設計大面積熱區 (Hotspots) 與防誤觸機制，降低戶外動態操作的困難度。

## 2. 本地端 AI 影像處理 (Edge AI / Image Processing)
- **智能去背技術：** 使用輕量化機器學習模型 (如 Flutter 的 tflite 或 ML Kit) 在手機本地端實現一鍵去背。
- **影像規格自動化：** 自動將編輯後的相片轉碼為 LINE 貼圖規範 (370x320 px, PNG-24, <1MB) 並自動留出 10px 邊距。

## 3. 本地優先數據管理 (Local-First Data Strategy)
- **高效存儲架構：** 利用 SQLite 或 Hive 進行本地文字感悟與元數據儲存，確保完全離線可用。
- **隱私沙盒機制：** 建立 App 專屬存儲空間，保護使用者私密相簿，避免數據被未授權 App 存取。

## 4. 全平台社交整合 (Social Connectivity)
- **原生分發協議：** 串接系統層級的分享 Sheet，確保支援 Threads、Instgram、LINE 等所有現有及未來的新興平台。
- **深度鏈結整合：** 處理特定的 LINE 貼圖包導出邏輯，降低上架門檻。

## 5. Flutter 跨平台開發生態 (Cross-Platform Dev)
- **Web/Mobile 混合開發：** 針對 Android Studio 安裝受限情況，靈活切換 Web 預覽模式與本地編譯。
- **響應式佈局：** 確保在各類大螢幕手機、平板上都能保持完美比例與間距。

---
*這些技能與技術將隨專案進展持續更新並優化。*
## 6. AI 記憶同步與連續性開發 (AI Memory Persistence & Continuity)
- **記憶實體化技術：** 透過 PROJECT_MEMORY.md 將對話中的非結構化決策（如名稱由來、風格偏好）轉化為結構化知識庫。
- **跨對話生命週期管理：** 利用「重啟指令」與「AI 規則錨點」，確保不同時間點、不同 AI 代理人對本專案的理解保持 100% 一致。
- **防錯機制 (Guardrails)：** 透過 AI_RULES.md 強制約束 AI 的開發邏輯，減少溝通成本並防止架構跑偏。
